SQL Practice

A small SQL practice project using SQLite.

Tools:
- SQL
- SQLite Online

Topics:
- SELECT and WHERE
- ORDER BY
- COUNT and GROUP BY
- LEFT JOIN
- NULL values

How to run:
1. Open (https://sqliteonline.com/).
2. Copy the contents of `queries.sql` into the SQL editor.
3. Execute the script.

The script creates sample employee and project tables with fictional data.
