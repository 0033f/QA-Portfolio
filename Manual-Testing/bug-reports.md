BUG-01: Employee ID accepts alphabetic characters

Environment: Windows 11, Google Chrome

Module: PIM > Add Employee

Preconditions: User is logged in and the Add Employee form is open.

Steps to Reproduce:

1. Enter a valid first name and last name.
2. Enter alphabetic characters in the Employee ID field.
3. Click Save.

Actual Result: The form accepts alphabetic characters and allows the employee to be created.

Expected Result: The Employee ID field should reject alphabetic characters if the specified format permits digits only.

Severity: To be determined based on the requirements and impact.

Evidence: Screenshot or other evidence, if available.
